# Manual Software Installation Guide

This guide lists software that needs to be manually installed outside of automated scripts.

## Hardware

- **MSI motherboard** - Should popup during system startup
- **AMD chipset** - Required for proper hardware support
- **MSI Mystic Light** - RGB lighting control software
- **Nvidia GPU driver** - [Download](https://www.nvidia.com/en-us/drivers/)
- **OBSBot Center** - [Download](https://www.obsbot.com/download/obsbot-meet-2)
- **NuphyIOn** - Nuphy keyboard software - [Download](https://drive.nuphy.io)

## Gaming

- **Battle.net** - Blizzard game launcher - [Download](https://download.battle.net/en-us/desktop)
- **Guild Wars** - [Download](https://www.guildwars.com/en/download)
- **World of Warcraft** - Available on Warmane or TauriWow servers
- **Other Games** - Install on Battle.net / Steam / EA App as needed

## Coding

- **Laravel Herd** - Local Laravel development environment - [Download](https://herd.laravel.com/download/latest/windows)

## Overclocking

- **AMD Ryzen Master** - CPU and RAM overclocking utility - [Download](https://www.amd.com/en/products/software/ryzen-master.html#download)
